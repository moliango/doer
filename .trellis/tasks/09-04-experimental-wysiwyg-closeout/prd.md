# 实验性编辑器收尾可默认开

## Goal

把实验性块编辑器补到日常回复不踩坑：撤销、当次编辑可切源码、工具栏和当前块对齐、跨块复制粘贴、图片/引用卡可删。开关仍默认关；缺口补齐后这条线了结。

## User Value

打开实验开关的人能写完一篇回复而不怕误操作无法撤销、看不懂工具栏、改不了投票、删不掉图。

## Confirmed Facts

- 回车/改块类型会 `rebuild()`，系统 `UITextView` 撤销栈被扔掉。
- 实验模式藏了 Aa/MD，出错只能去设置关开关。
- 投票保存走 `composerInsertRaw`，没整段选中 `[poll]` 时会再插一份。
- 图片岛不可点、不可单独删除。
- 选区不能跨块。回复 @ 已接当前块可视文字，重建后浮层可能飘。

## Requirements

- 结构性编辑（回车拆块、合并、插图、改标题/列表/引用、插多块）可撤销/重做；摇一摇和 Cmd-Z 有效。
- 当次编辑能在实验块视图和源码框之间切换，不卸载内核、不丢草稿；切回实验时 `tryLoad` 失败则留在源码框。
- 工具栏反映当前块：标题/引用/列表/粗斜体/删除线/代码/投票高亮；再点即关掉。
- 光标在投票 literal 上打开投票构建器，保存替换该块，不另插一份。
- 图片岛可预览、可删除；引用卡可删除。
- 能选中连续多块并复制/剪切/删除/粘贴为 markdown 块。
- 长按拖动可调整块顺序。
- 有序列表在中间插入后序号连续；划选多段可变成列表。
- 引用工具可嵌套一层 `>`，再点减一层，没有 `>` 则退回段落。
- 预览关闭后焦点回到原块和光标。
- 回复 @ 在重建后仍贴着当前块光标。
- 发帖/私信同样具备撤销、源码切换、工具栏、跨块、图片删除（@ 仍只在回复里，与旧编辑器一致）。
- `experimentalRichComposerEnabled` 默认 **true**；设置里仍可关掉。

## Acceptance Criteria

- [x] Cmd-Z / 摇一摇能撤掉回车拆段和插入的图片。
- [x] 实验模式下 Aa/MD 可切到源码再切回块视图，正文还在。
- [x] 光标在二级标题时标题工具为选中；再点变回段落。
- [x] 光标在 `[poll]` literal 上改投票，全文只有一份 poll。
- [x] 点图片能删掉该岛，光标落到相邻可编辑块。
- [x] 选中两段复制，粘贴后仍是两块。
- [x] 预览开关后再看见原来的光标块。
- [x] 默认开关打开；关掉后旧 Aa/MD 路径不改。

## Out Of Scope

- Discourse cook JS、IR 显形。
- 投票/宫格/policy 做成所见即所得孤岛（继续 literal）。
- 发帖/私信加 @。
- 把实验开关改成默认开。
