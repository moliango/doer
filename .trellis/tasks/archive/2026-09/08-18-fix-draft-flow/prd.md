# 草稿流程修复

## 需求

1. 移除面向用户的本地草稿：编辑器只使用 Discourse 云端草稿，草稿列表不再展示本机草稿。
2. 打开云端新主题草稿时，正确恢复标题、正文、分类和标签。
3. 编辑器提供“保存草稿”操作；保存后保留云端草稿并退出编辑器。
4. “舍弃”必须删除对应云端草稿后退出，不能因为 `viewWillDisappear` 再次保存出一份新草稿。
5. 发布/发送成功后删除对应云端草稿；回复、私信和新主题流程行为一致。

## 约束

- 保留本地的云端 `draft_sequence` 缓存，它不是用户可见的本地草稿，仍用于 Discourse 乐观并发控制。
- 不改变现有 Discourse 草稿 API 和发布 API 合约。
- 所有用户可见文本使用本地化字符串。

## 验收标准

- 草稿列表只有云端草稿；输入内容不会写入 `composer.local_draft.*`。
- 云端新主题草稿的分类和标签显示为已选中状态。
- 保存草稿后再次打开仍能恢复内容、分类和标签。
- 舍弃云端草稿后刷新列表，草稿消失；不会新增同内容草稿。
- 发布/发送成功后草稿消失。
- DraftRoutingTests 及新增的草稿数据/提交行为测试通过。
