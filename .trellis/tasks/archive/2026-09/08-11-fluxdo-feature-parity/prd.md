# FluxDo Feature Parity — PRD

## Goal
Port FluxDo v0.2.26 high-value features into DexoFlux across three phases.

## Phase 0 (MVP)
1. Mark topic unread (step back one floor / clear all progress)
2. New private message from Messages list
3. Poll reading UX polish (results + optional pie)
4. Related/suggested topics at end of topic

## Phase 1
1. discourse-assign (assign topic/post)
2. post-voting (Q&A)
3. Poll create in composer
4. Nested tree from notification + fallback
5. Unread badge realtime refresh

## Phase 2
1. Site Chat (channels)
2. QR cross-device login
3. iPad dual-column “平行视界”
4. Video resume
5. Follow user activity (“追觅”)
6. Instant markdown render (deferred if time)

## Non-goals (this epic)
- Full WYSIWYG rewrite
- Desktop multi-window workspace parity
