# 图片不闪

## Goal

刷过的图不要先灰一下再出来；看图能跟手关掉；进帖里的图不要空一帧。

## Confirmed Facts

- 磁盘解码已离开主线程；内存命中仍同步。冷启动第一次从磁盘出图可能先占位。
- 话题看图是自定义 gallery，没有共享元素 Hero，没有跟手关闭。话题返回已经用系统边缘手势。
- Cloudflare 图有 gate/grace，改绑图时不能重新引发盾闪。

## Requirements

- 内存命中：立刻出图，不闪占位。
- 磁盘命中：用稳定底色或上一帧，淡入最终图，避免灰块闪一下。
- 看图：支持跟手下滑/关闭（与系统返回手感同类），不要先缩小再飞。
- 进帖正文图与头像走同一套「内存同步、磁盘不闪灰」策略。
- 不把磁盘解码搬回主线程。

## Acceptance Criteria

- [x] 同一进程内再次滚到已看过的图：无占位闪。
- [x] 冷启动后磁盘命中：无明显灰块闪（允许极短淡入）。
- [x] 看图可用下滑关掉，中途松手可取消。
- [x] CF 挑战期间不出现盾闪烁回归。

## Out Of Scope

- FluxDO 一镜到底 Hero 从卡片飞到查看器（可后做）。
- 启动闪屏（A）。
